## About the Project

SmartHire is an AI-powered recruitment platform designed to simplify resume screening and candidate evaluation.

The platform analyzes candidate resumes against job requirements, helping recruiters assess suitability through candidate match scores, skill-gap analysis, and AI-generated insights.

By bringing resume analysis, candidate comparison, and evaluation tools together, SmartHire aims to make the initial stages of recruitment more organized and efficient.

## Key Features

### 1. AI Resume Analysis
- Extracts information from uploaded PDF and DOCX resumes.
- Analyzes candidate profiles against specified job requirements.
- Evaluates candidate suitability based on relevant information.

### 2. Intelligent Candidate Ranking
Candidates are scored and ranked based on factors such as:
- Skills match
- Experience relevance
- Educational background
- Projects and certifications

### 3. Skill Gap Analysis
Identifies:
- Skills that match the job requirements.
- Missing or insufficient skills.
- Areas where candidates could improve.

### 4. AI-Generated Candidate Insights
Provides candidate-specific insights, including:
- Candidate summaries.
- Skill-gap analysis.
- Potential red flags.
- Tailored interview questions.

### 5. Recruiter Dashboard
Recruiters can:
- Create job roles with specific requirements.
- Upload multiple candidate resumes.
- View candidate rankings.
- Review detailed candidate profiles and analysis.

### 6. Resume Parsing
Supports resume extraction from:
- PDF files using PDF.js.
- DOCX files using Mammoth.js.

### 7. Candidate Data Export
Allows recruiters to export candidate evaluation data in:
- CSV format.
- Excel format.

## How It Works

1. The recruiter creates a job role with the required skills and experience.
2. Candidate resumes are uploaded to the platform.
3. Resume information is extracted from the uploaded files.
4. The extracted information is analyzed against the job requirements.
5. Candidates receive a match score from 0–100.
6. Candidates are ranked based on their evaluation.
7. Recruiters can review detailed candidate insights and use them to support their screening process.
